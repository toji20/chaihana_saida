# Чайхана — landing page

Адаптивный лендинг на Next.js 15, React 19 и TypeScript. Включает все блюда и цены из исходного меню, категории, поиск по текущей категории, блоки о заведении, избранные позиции и ссылку на Яндекс Карты.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Перед публикацией

- В `app/page.tsx` замените временное название «Чайхана» на точное название заведения.
- Уточните адрес, телефон, график работы и добавьте их в секцию контактов.
- Замените демонстрационные изображения Unsplash на реальные фотографии блюд и интерьера.
- Проверьте цены и наличие блюд перед запуском.

Ссылка на Яндекс Карты из запроса уже добавлена в кнопки маршрута. Фотографии загружаются с Unsplash, шрифты — Google Fonts.
